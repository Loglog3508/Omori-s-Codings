- 仓库不包含以下本地目录（已在 `.gitignore` 中排除）：`人才库/`（人才数据采集）、

- 大于 GitHub 普通文件限制的二进制文件（`*.zip`、`*.mp4`、`*.7z`、`*.sqlite`）使用 Git LFS 管理。
