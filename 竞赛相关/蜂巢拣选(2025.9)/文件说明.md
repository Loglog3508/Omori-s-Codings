## 数据文件
### 仓储数据集.sqlite
包含表 `Picking_orders`：字段示例 `pick_order_id`, `pn_no`, `ship_num`, `position`, `ship_station`, `created_time`, ...。入口脚本读取该表构建分析基础数据。

## 核心包：`蜂巢分析/`
### 1. `__init__.py`
作用：集中导出所有子模块对外可用的类与函数，方便 `from 蜂巢分析 import ...` 直接引用。
导出内容包括：
- 数据处理：`data_cleaning`, `feature_engineering`
- 指标画像：`calculate_eiq_metrics`, `eq_analysis`, `en_analysis`, `iq_analysis`, `ik_analysis`
- 分类与联合分析：`abc_classification`, `eiq_abc_matrix_analysis`, `generate_operational_guidance`, `plot_quadrant_scatter`
- 优化策略：`storage_location_optimization`, `picking_strategy_recommendation`, `path_optimization`
- 评估与报告：`cost_benefit_analysis`, `summarize_benefits`, `generate_analysis_report`, `render_visual_dashboard`, `export_plan_text`, `export_plan_to_excel`, `initialize_plot_style`, `save_report`
- 配置/数据类：`ABCConfig`, `EIQConfig`, `SystemConfig`, `WarehouseLayout`, `BaselineMetrics`

### 2. `etl.py`
功能：数据清洗与特征工程。
主要函数：
- `data_cleaning(df)`：去重、数值缺失填充 0、文本缺失填充 "未知"、日期字段转时间戳。
- `feature_engineering(df)`：返回 `(订单特征, SKU画像)` 两个 DataFrame。
输入：原始订单 DataFrame；输出：清洗后 DataFrame + 特征集合。

### 3. `eiq.py`
功能：计算 EIQ 体系核心指标，支持订单频次、SKU 数量占比等。
主要函数：
- `calculate_eiq_metrics(df)`：按 SKU 聚合频次与数量、位置信息等。
- `eq_analysis(df)`：返回 (按日订单数 Series, 按月订单数 Series)。
- `en_analysis/iq_analysis/ik_analysis(df)`：分别输出订单行数分布、SKU 出库量分布、SKU 订单参与次数分布。
输入：清洗后订单；输出：指标表与多个 Series。

### 4. `abc.py`
功能：基于累计占比进行 A/B/C 分类（可按数量或价值）。
主要函数：
- `abc_classification(metrics_df, config)`：在指标表上增加 `cum_share` 与 `abc_category`。
配置：`ABCConfig(value_method='quantity'|'value', thresholds=(0.7,0.9,1.0))`。

### 5. `matrix.py`
功能：将 EIQ 指标与 ABC 分类结果融合，生成四象限并给出基础运营建议。
主要函数：
- `eiq_abc_matrix_analysis(eiq_df)`：添加 `frequency_tier`、`matrix_segment` 返回象限详情与分布统计。
- `generate_operational_guidance(matrix_df)`：为不同象限填充储位、策略、路径建议。
- `plot_quadrant_scatter(matrix_df)`：绘制散点图，横轴频次占比、纵轴数量占比，颜色区分象限、形状区分 ABC 等级。
输出：增强后的 DataFrame（带建议字段）、象限数量统计 Series。

### 6. `optimization.py`
功能：将分析结果映射到仓储布局与拣选策略。
主要对象：`WarehouseLayout(golden_zone, reserve_zone, edge_zone)`。
主要函数：
- `storage_location_optimization(recommendations, layout)`：按象限挑选适合储位列表。
- `picking_strategy_recommendation(recommendations)`：按象限返回策略方法与优先级字典。
- `path_optimization(orders, layout_mapping)`：用简单距离模型估算订单拣选路径长度（示意用，可扩展为真实坐标路径规划）。

### 7. `evaluation.py`
功能：对比优化前后关键指标，形成节省比例与产能提升。
数据类：`BaselineMetrics(walking_distance, picking_time, labor_cost, throughput)`。
主要函数：
- `cost_benefit_analysis(before, after)`：生成节省/提升百分比字典。
- `summarize_benefits(report_dict)`：转为 DataFrame，便于合并进报告。

### 8. `reporting.py`
功能：报告与输出整合。
主要函数：
- `generate_analysis_report(sections)`：将分节 DataFrame 合并成统一表并加 `Section` 字段。
- `save_report(df, path)`：保存 CSV 报告。
- `initialize_plot_style()`：自动选择本地可用中文字体（SimHei、微软雅黑等）。
- `render_visual_dashboard(eq_daily, eq_monthly, sku_profile, abc_counts, segment_summary, path)`：生成 2x2 综合图（近日趋势、月度对比、Top10 SKU、ABC+象限分布）。
- `export_plan_to_excel(sections, path)`：多 sheet Excel 导出（缺少依赖自动跳过）。
- `export_plan_text(...)`：输出优化方案关键要点到 txt。

### 9. `config.py`
功能：集中存放系统级阈值与仓库约束。
数据类：`SystemConfig(abc_thresholds, ik_threshold, warehouse_constraints)`；函数：`default_config()`。

## 入口脚本与辅助脚本
### 蜂巢智能拣选主流程.py
完整执行步骤：
1. 字体初始化（中文正常显示）。
2. 载入 SQLite 订单数据。
3. 数据清洗与特征工程。
4. EIQ 指标计算 + 日/月订单趋势获取。
5. ABC 分类与 EIQ-ABC 象限分析，生成运营建议。
6. 布局派位、拣选策略映射、效益模拟。
7. 报告生成（CSV、文本方案、可选 Excel）。
8. 可视化输出（象限散点图 + 综合仪表盘）。
输出统一写入 `output/` 目录。

关键内部辅助函数（入口脚本定义）：
- `load_orders()`：读取数据库并规范数值字段。
- `build_quality_report()`：生成数据质量汇总表。
- `derive_layout()`：根据订单出现的库位粗略构造布局分区。
- `simulate_benefits()`：构造基准与优化后指标并计算节省比例。
- `prepare_recent_months()`：截取实际存在的最近若干月订单数（不补零）。

### 矩阵图.py
快速单独展示工位与象限发货数量热力图：
1. 载入必要字段（工位、SKU、数量）。
2. 计算 EIQ 指标 + ABC 分类 + 象限划分（复用 `蜂巢分析` 内逻辑）。
3. 生成工位×象限透视表（Top N 工位）。
4. 绘制热力图并标注数量。
用途：无需跑完整流水线即可检查象限与工位分布合理性。

## 依赖与环境
- 必需：`pandas`, `matplotlib`, `sqlite3`（标准库）
- 可选：`xlsxwriter` 或 `openpyxl`（启用 Excel 多 sheet 导出）
- 字体：脚本自动寻找本地常见中文字体；若无则可能出现方块字符，可手动安装。

## 输入输出关系概览
| 阶段 | 输入 | 处理/函数 | 输出 |
|------|------|----------|------|
| 数据读取 | SQLite 表 | `load_orders` | 原始订单 DataFrame |
| 清洗特征 | 原始订单 | `data_cleaning`, `feature_engineering` | 清洗数据 + 订单 & SKU 特征 |
| 指标计算 | 清洗数据 | `calculate_eiq_metrics`, `eq_analysis` | EIQ 指标表 + 日/月趋势 |
| 分类分析 | 指标表 | `abc_classification` | 带 ABC 分类的表 |
| 联合象限 | 分类表 | `eiq_abc_matrix_analysis` | 增强表 + 象限统计 |
| 运营建议 | 象限表 | `generate_operational_guidance` | 储位/策略/路径建议列 |
| 优化映射 | 建议表 + 布局 | `storage_location_optimization`, `picking_strategy_recommendation` | 储位方案 + 策略字典 |
| 效益模拟 | 象限统计 + 订单数 | `simulate_benefits` + `cost_benefit_analysis` | 节省指标 DataFrame |
| 报告导出 | 汇总 sections | `generate_analysis_report`, `save_report`, `export_plan_text` | CSV / 文本 / 图表 / 可选 Excel |

## 扩展建议
1. 路径优化：将 `path_optimization` 替换为真实坐标 + TSP / A* 算法，提高路径估算准确性。
2. 动态阈值：`MatrixConfig.frequency_threshold` 可扩展为按分位数或滑动窗口自适应。
3. 多维价值：在 `abc.py` 中增加复合价值列（销售额 × 毛利 × 周转率等）。
4. 缓存层：对大规模数据引入增量计算（只更新新增订单）。
5. Web 化：封装为 FastAPI / Streamlit 服务，支持在线交互与实时图表。

## 常见问题
- 月度对比只出现 3 个月：数据库仅含 2017-01 ~ 03，脚本现在按实际月份展示不补零。
- Excel 未生成：未安装 `xlsxwriter`/`openpyxl`；安装后重跑即可。
- 中文字体警告：系统缺少指定字体，安装任一黑体或微软雅黑后重跑。
