# 商务数据分析：大学生哑铃市场分析

## 一、项目背景

本课程作业拟运营的产品为 **2-20kg 宿舍友好型可调节哑铃套装**：可拆卸、包胶降噪、占地小、适合新手渐进式训练。小组确认主推价 59 元，价格带 49-69 元。

目标人群为全国普通本科、职业本科与高职（专科）在校生。分析目标是对应课堂口径，完成目标市场规模、市场趋势、生命周期与红蓝海判断。

## 二、核心结论

1. 通用可调节哑铃是**成熟红海**品类，不建议进入 13.8 元至 30 元的低价混战。
2. 细分机会来自宿舍场景属性：静音包胶、小空间收纳、轻量渐进配重、新手训练内容。
3. 线下机会值（潜在客户 3891.26 万人 × 主推客单价 59 元）：购买意愿 5%、10%、15% 情景下分别约 1.15 亿元、2.30 亿元、3.44 亿元。这三个比例是情景假设，正式提交前需用问卷替换。
4. 搜索需求：百度指数“哑铃”近 12 个月趋势代理同比为 -22.9% 至 -40.0%，按课堂阈值落入衰退区间；完整表述为“成熟期向衰退期过渡、短期需求偏弱”，不代表整个健身器材行业衰退。
5. 线上最终规模口径为生意参谋叶子类目近 30 天前 500 品牌成交额（当前待补）；淘宝 TOP10 可见销量下限仅 13900 件、GMV 下限约 57.51 万元，不能当作全行业规模。

## 四、工作簿结构

`大学生哑铃_市场分析数据与计算.xlsx` 共 7 个工作表：

- `使用说明`：文件状态、口径、数据使用警告与产品边界。
- `淘宝TOP10`：关键词“可调节 哑铃 宿舍”销量排序 TOP10 的价格、店铺与可见销量下限。
- `生意参谋TOP10（7天）`：哑铃叶子类目 2026-09-03 至 2026-09-09 交易总量商品 TOP10。
- `生意参谋店铺TOP10（30天）`：哑铃叶子类目近 30 天店铺交易总量 TOP10。
- `市场规模`：线下情景法与线上样本法/大盘法的公式与录入位。
- `百度指数录入`：12 条月度趋势代理值及同比、环比公式。
- `数据来源`：来源、日期、可用数据、证据等级与使用限制。

> 黄色底、蓝色文字为待用户填写的输入项，黑色文字为公式结果。
