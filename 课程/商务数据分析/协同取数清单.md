# 大学生哑铃：协同取数清单

本清单只包含必须由拥有权限或处在校园现场的组员完成的动作。完成后把数值或截图发到本线程，即可写入最终市场规模结论。

## A. 生意参谋市场大盘

前置条件：使用已经开店、能进入生意参谋市场模块的淘宝商家账号。现已登录“卡哇伊丶小店 主店”，可进入市场模块；但2026-09-10的市场排行页面返回“数据加载错误”，切换类目时曾出现异常访问限制。请在限制解除、榜单正常加载后再继续取数。

操作：

1. 登录有店铺权限的生意参谋账号。
2. 进入“市场”或“市场大盘”。
3. 类目选择最贴近哑铃的**叶子类目**。记录完整类目路径，例如“运动/瑜伽/健身/球迷用品 > 健身训练器材 > 哑铃/杠铃”，不要只写“大类”。
4. 时间范围选“近30天”，记录起止日期。
5. 记录市场大盘的交易额、销量、支付买家数、同比和环比。
6. 进入品牌排行，按交易额排序。可见前500品牌时，导出数据；不能导出时按页面/截图记录每页交易额并求和。
7. 截取以下页面：类目路径和时间、市场大盘核心指标、品牌排行第一页、品牌排行最后一页或导出结果。

## B. 大学生购买意愿问卷

目标：将线下市场公式中的“购买意愿”从情景假设替换为一手数据。建议只发给大学生，样本至少30份，有条件时50份以上。

题目：

1. 你的身份：本科 / 高职专科 / 研究生 / 其他（仅保留前三类大学生样本）。
2. 你当前主要居住场景：宿舍 / 校外合租 / 家中 / 其他。
3. 你近3个月是否有力量训练或居家健身需求：有 / 没有 / 不确定。
4. 如果产品是“静音包胶、可收纳、可调节重量”的宿舍哑铃套装，你是否愿意在未来6个月购买：愿意 / 可能愿意 / 不愿意。
5. 你可以接受的价格：30元以下 / 30-49元 / 50-69元 / 70-99元 / 100元以上。
6. 你最在意的因素（最多选3项）：价格 / 静音 / 收纳 / 重量可调 / 外观 / 品牌 / 训练教程 / 售后。
7. 你担心的主要问题：噪音 / 占空间 / 安全 / 无用闲置 / 价格 / 不担心。

计算方法：

```text
购买意愿 = （“愿意”人数 + 0.5 × “可能愿意”人数）÷ 有效大学生样本数
```

说明：把“可能愿意”按0.5折算，是为了避免将犹豫样本全部计入或全部排除。若老师要求只统计明确意愿，可改为“愿意人数 ÷ 有效样本数”，并在汇报中说明口径。

填写位置：`大学生哑铃_市场分析数据与计算.xlsx` -> `市场规模` -> 黄色单元格 `C4:C6`。可将低、基准、高情景设置为问卷结果的80%、100%、120%。
