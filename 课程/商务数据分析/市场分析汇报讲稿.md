# 大学生哑铃市场分析汇报讲稿

## 第1页：项目与结论

我们拟运营的产品是“2至20kg宿舍友好型可调节哑铃套装”，核心特点是可拆卸、包胶降噪、占地小、适合新手渐进式训练；主推价59元，价格带49元至69元。

先给结论：通用可调节哑铃是成熟红海品类，不建议进入13.8元至30元的低价混战；但“大学生宿舍”这个场景存在细分机会，机会来自静音、小空间、入门训练和可收纳，而不是单纯压低价格。

## 第2页：为什么选择大学生哑铃

目标人群是普通本科、职业本科和高职学生。教育部统计显示，2024年全国普通、职业本专科在校生3891.26万人，目标群体规模足够大。

大学生的痛点不是专业健身房装备，而是宿舍空间有限、担心噪音、预算有限、缺少训练指导。因此产品必须围绕“可收纳、静音、安全、低门槛”设计。

## 第3页：行业与数据来源

产品属于体育用品及相关产品制造、居家健身器材细分。2024年全国体育产业总产出38421亿元，其中体育用品及相关产品制造增加值4245亿元。这个数据说明行业基础，但不是哑铃市场规模，不能直接套用。

本报告使用四类数据：

1. 教育部：计算大学生潜在客户。
2. 淘宝：采集竞品、价格、店铺和销量排序样本。
3. 百度指数：观察搜索需求变化。
4. 生意参谋：获取近30天行业大盘及前500品牌数据。

补充行业报告背景：国家体育总局转载的年度报告显示，2024年健身器材电商销售额为161.06亿元；2025年健身器材在2024年高速增长后出现小幅回调。这两项均属于健身器材大类，只用于说明外部环境，最终项目规模仍以哑铃关键词样本和生意参谋前500数据为准。

## 第4页：竞争产品、店铺与定价

淘宝以“可调节 哑铃 宿舍”搜索并按销量排序，结果页有33页，供给较多。

TOP10样本中的重点竞品店铺包括：

- Umay佑美旗舰店
- 裕迅旗舰店
- 朗威旗舰店
- 品健运动旗舰店
- 多珂星旗舰店
- 超森健身

TOP10展示价在13.80元至89.00元，均值40.33元，中位数27.30元。低价段商品密集，且存在“全网低价”“超级爆款”等表述，说明价格竞争强。

建议的运营定价不是跟随最低价，而是将2至20kg、静音包胶、可收纳和训练内容打包，形成49元至69元的中端价位，主推59元。这个价格区间高于样本中位数，但低于头部品牌的高配展示价，才有空间覆盖品质、包装和售后。

## 第5页：市场规模计算

线下目标市场使用课堂公式：

```text
市场规模 = 潜在客户数量 × 购买意愿 × 客单价
```

以3891.26万名学生和59元主推客单价计算：

- 购买意愿5%：约1.15亿元
- 购买意愿10%：约2.30亿元
- 购买意愿15%：约3.44亿元

这里的5%、10%、15%是情景假设，不是问卷结论。40.33元是淘宝竞品样本均价，只作价格带参照；正式提交前，需要收集至少30份目标学生有效问卷，用真实购买意愿替换。

线上样本方面，淘宝TOP10中可量化的7个商品，按“人收货”的下限合计为13900件，对应GMV下限575110元。这个数是TOP10样本的保守下限，不是全行业规模。

生意参谋补充验证了哑铃叶子类目的交易集中度。2026年9月3日至9月9日、按交易总量查看的商品TOP10中，支付买家数区间合计为28750至61000人，访客数区间合计为28万至62.5万人。Keep官方旗舰店、Umay佑美旗舰店、朗威旗舰店、品健运动旗舰店、迪卡侬旗舰店和裕迅旗舰店均进入TOP10。该口径是7天商品TOP10的支付买家区间，不能写成30天销量或行业GMV。

近30天店铺榜单进一步显示，Keep官方旗舰店、Umay佑美旗舰店、朗威旗舰店的支付金额排名为前3；TOP10店铺访客数区间合计232.5万至410万。该页面只显示支付金额排名、不显示金额，所以能证明流量和头部店铺集中，不能直接计算行业GMV。

## 第6页：红海、蓝海与生命周期

红海判断：

1. 搜索结果33页，供给端充分。
2. 低价段密集，价格区间宽。
3. 头部店铺已形成品牌和回头客积累，例如Umay佑美旗舰店显示回头客10万，品健运动旗舰店显示回头客5万。
4. 生意参谋哑铃类目7天交易总量TOP10中，Keep官方旗舰店占3个商品位，头部品牌集中度进一步验证了通用品类的竞争壁垒。
5. 生意参谋近30天店铺交易总量排名中，Keep、佑美、朗威位列支付金额前3，说明品牌店铺在该类目占据显著位置。

细分机会：

1. 宿舍静音包胶。
2. 小空间收纳和可拆卸。
3. 2至20kg渐进配重。
4. 入门训练计划与新手内容。

百度指数当前数据：2026年8月11日至9月9日，“哑铃”整体日均搜索指数361，同比-29%，环比-8%。按课堂阈值，这是一段短期下行信号。

同日切换“全部”范围（2011年1月1日至2026年9月9日）的整体日均值为1106、移动日均值为716，证明平台可提供长期序列，但该均值不能与30天均值直接比较。当前更稳妥的判断是：通用哑铃处于成熟红海，短期搜索需求偏弱；是否进入衰退期，需要补录至少12个月百度指数并排除季节性影响。

如果课堂必须按增长率直接归类，则本观察期同比-29%低于-10%，可归入“衰退区间”；完整表述应为“通用哑铃为成熟红海品类，当前处于成熟期向衰退期过渡，短期需求下行”。

## 第7页：下一步取数与运营建议

最关键的待补数据是生意参谋近30天大盘。当前已取得哑铃类目7天商品TOP10，以及近30天店铺TOP10的支付金额排名和访客区间；课程所要求的近30天前500品牌成交额、销量和同比环比在当前免费榜单中未显示，不能自行补算。

运营建议：

1. 不进入低价通用哑铃竞争。
2. 选择宿舍友好定位，主打静音、收纳与入门训练。
3. 用真实问卷替换购买意愿情景假设。
4. 用生意参谋前500成交额确定最终线上市场规模。
5. 用百度指数12个月趋势完善生命周期结论。

## 讲稿更新：百度指数12个月证据

前面“仍需补录12个月趋势”的工作已经完成。我们在百度指数中查询“哑铃”，范围为全国、PC+移动，时间为2024年9月1日至2026年8月31日。因为长区间趋势图按周展示，我们按每月一条可见周值、并配对去年相近周，作为趋势代理，避免把周值说成月均指数。

从2025年9月至2026年8月，12条趋势代理同比全部为负，落在-22.9%至-40.0%之间。例如，2025年9月为500、去年同期693，同比-27.8%；2026年6月为389、去年同期648，同比-40.0%；2026年8月为365、去年同期519，同比-29.7%。而最近30天（2026年8月11日至9月9日）的整体同比为-29%、环比为-8%，方向一致。

所以这一页的最终口径是：**通用可调节哑铃属于成熟红海品类；从连续12个月的搜索趋势代理和近30天指标看，需求增速落在衰退区间，行业处于成熟期向衰退期过渡、短期需求偏弱。** 这里的“衰退”描述的是关键词需求信号，不是对整个健身器材大行业作绝对判断。
