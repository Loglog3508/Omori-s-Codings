# 机器学习

《机器学习》课程实验材料，按实验分文件夹整理。

| 实验 | 题目 | 文件夹 | 说明 |
| --- | --- | --- | --- |
| 实验一 | 逻辑回归 | `实验一/` | 含课程提供的代码与数据 `纯python代码1/`（logistic_regression.py + wine.data）、`纯python代码2/`（lr_train.py、lr_test.py + data.txt、test_data） |
| 实验二 | 聚类（K-Means） | `实验二/` | 含课程提供的代码与数据 `纯python代码1/`（kmeans.py + seeds_dataset.txt）、`纯python代码2/`（kmeans_utils.py 与 3 个示例），并在此基础上做了改进 |
| 实验三 | 决策树 | `实验三/` | 含课程提供的代码 `实验三/决策树/纯python代码1/`（分类树 decision_tree.py、分类回归树 cart_classification.py / cart_regression.py）、`纯python代码2/`（id3.py、c45.py、cart.py 与 demo）。围绕 ID3 / C4.5 / CART，用天气数据、种子数据集和自选数据（wine 分类、diabetes 回归）完成 3 个任务 |
| 实验四 | 深度学习初步 | `实验四/` | 使用纯 NumPy 实现感知机、二层与三层神经网络和误差反向传播；通过梯度检查验证实现，并完成双月、同心圆和手写数字分类实验 |

其他文件：
- `《机器学习》实验指导书.doc`：课程实验指导书。

每个实验文件夹下都有 `README.md`（实验说明与结果）、`结果图/`（运行产生的图片）、`data/`（数据集）和 `机器学习实验X报告.docx`（实验报告）。
