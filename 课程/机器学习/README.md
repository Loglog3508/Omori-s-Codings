# 机器学习

《机器学习》课程实验材料，按实验分文件夹整理。

| 实验 | 题目 | 文件夹 | 说明 |
| --- | --- | --- | --- |
| 实验一 | 逻辑回归 | `实验一/` | 含老师提供的代码与数据 `纯python代码1/`（logistic_regression.py + wine.data）、`纯python代码2/`（lr_train.py、lr_test.py + data.txt、test_data） |
| 实验二 | 聚类（K-Means） | `实验二/` | K-Means 由自己用 numpy 实现（`纯python代码1_KMeans聚类.py`），数据为种子数据集与手写数字数据集 |

其他文件：
- `《机器学习》实验指导书.doc`：课程实验指导书。

每个实验文件夹下都有 `README.md`（实验说明与结果）、`结果图/`（运行产生的图片）、`data/`（数据集）和 `机器学习实验X报告.docx`（实验报告）。
