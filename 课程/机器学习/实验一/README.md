## 三、核心原理
### 1. 模型
逻辑回归是二分类模型，先用线性函数计算得分，再用 Sigmoid 函数映射为概率：

```
z = w^T x + b
ŷ = σ(z) = 1 / (1 + e^(-z))
```

当 ŷ ≥ 0.5 判为类别 1，否则判为类别 0。

### 2. 损失函数（交叉熵）
```
J(w, b) = -(1/m) * Σ [ y·ln(ŷ) + (1-y)·ln(1-ŷ) ]
```

### 3. 梯度
```
∂J/∂w = (1/m) * X^T (ŷ - y)
∂J/∂b = (1/m) * Σ (ŷ - y)
```

### 4. 两种优化方法
- **梯度下降（代码 1）**：用一阶梯度沿负梯度方向迭代更新，需要较多迭代次数。
  `w ← w - α·∂J/∂w`
- **牛顿法 / IRLS（代码 2）**：利用二阶导数（Hessian 矩阵）信息，每次直接求解线性方程组 `w ← w - H^(-1)·g`，收敛更快、迭代次数更少。

### 5. 多分类（One-vs-Rest）
将多分类任务拆成"一个类别对剩余类别"的多个二分类器，最后取概率最大的类别作为预测结果。
