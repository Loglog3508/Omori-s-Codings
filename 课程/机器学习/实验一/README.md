## 三、核心原理
### 1. 模型
逻辑回归是二分类模型，先用线性函数计算得分，再用 Sigmoid 函数映射为概率：
```
z = w^T x + b
ŷ = σ(z) = 1 / (1 + e^(-z))
```
当 ŷ ≥ 0.5 判为类别 1，否则判为类别 0。

### 2. 损失函数（交叉熵）
```
J(w, b) = -(1/m) * Σ [ y·ln(ŷ) + (1-y)·ln(1-ŷ) ]
```

### 3. 梯度
```
∂J/∂w = (1/m) * X^T (ŷ - y)
∂J/∂b = (1/m) * Σ (ŷ - y)
```

### 4. 老师提供的两份纯 Python 代码
- **纯python代码1（`logistic_regression.py`）**：面向对象写法，`class LogisticRegression`。
  `train()` 先给 X 增加一列 `x0 = 1`（偏置项），再用**批量梯度下降**更新权重；
  支持 `tol` 早期停止法；`predict()` 返回 0/1 类别。`loss_list` 记录了每轮损失，可直接画收敛曲线。
- **纯python代码2（`lr_train.py` + `lr_test.py`）**：脚本式写法，用 `np.mat` 做矩阵运算。
  `lr_train_bgd()` 实现批量梯度下降，`save_model()` 保存权重，`error_rate()` 计算交叉熵损失；
  `lr_test.py` 负责 `load_weight()` → `load_data()` → `predict()` → `save_result()` 的完整预测流程。

### 5. 两个需要注意的实现细节
- **NumPy 版本兼容**：`lr_train.py` / `lr_test.py` 使用了 `np.mat`，而 NumPy 2.0 已经移除该函数，
  因此 `task4_数据集分类_代码2.py` 开头加了兼容处理 `np.mat = np.asmatrix`，让老师提供的代码能直接运行。
- **特征标准化**：`wine.data` 的 13 个特征量纲差别极大（脯氨酸 278~1680，苹果酸只有 0.74~5.8），
  不标准化时梯度下降会震荡甚至数值溢出；标准化后收敛又快又稳。任务 4 的二维数据量纲接近，
  可以直接用老师代码的原始设置。

## 七、主要实验结果
- **任务 3（红酒数据集）**：用老师提供的代码 1 训练，训练集与测试集准确率都是 **1.0000**，
  混淆矩阵 `[[18, 0], [0, 21]]`，最终损失 0.0008；只取前 2 个特征（酒精、苹果酸）时测试集准确率为 0.8462。
  标准化后权重绝对值最大的特征是 Proline（-4.438）、Alcohol（-3.844）、Alcalinity of ash（3.344）。
- **任务 4（二维数据集）**：复现老师代码 2 的原始流程得到权重 `[1.3942, 4.5272, -4.794]`，
  对 `test_data` 的 200 个样本预测为类别 1 的有 100 个；按 7:3 划分训练/测试集后测试集准确率为 **1.0000**，
  混淆矩阵 `[[31, 0], [0, 29]]`。
- **任务 5（乳腺癌，sklearn）**：准确率 0.9860，精确率 / 召回率 / F1 均为 0.9889，AUC = 0.9977。
