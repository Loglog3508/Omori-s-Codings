## 三、核心原理
### 1. ID3：用信息增益选特征
```
信息熵        Ent(D) = -Σ p_k · log2(p_k)
条件熵        Ent(D|a) = Σ_v (|D^v|/|D|) · Ent(D^v)
信息增益       Gain(D,a) = Ent(D) - Ent(D|a)
```
ID3 每次选择**信息增益最大**的特征做分裂；缺点是偏向取值较多的特征（取值越多，分裂得越“碎”，
条件熵越容易被压低）。

### 2. C4.5：用信息增益率选特征，并能处理连续值
```
分裂信息       IV(a) = -Σ_v (|D^v|/|D|) · log2(|D^v|/|D|)
信息增益率     Gain_ratio(D,a) = Gain(D,a) / IV(a)
```
信息增益率除以“分裂信息”，抑制了 ID3 对多取值特征的偏好。对**连续特征**，C4.5 把相邻取值的中点
作为候选分裂点，二分后计算信息增益率，取最大者，学出形如 `humidity <= 70.0` 的分裂。

### 3. CART：用 Gini 系数，既能分类也能回归
```
Gini 系数      Gini(D) = 1 - Σ_k p_k²
分类：选择使划分后 Gini 最小的特征与切分点（二叉分裂）
回归：用 MSE（节点内方差）代替 Gini，叶子取样本均值
```
CART 是**二叉树**；分类树用 Gini，回归树用 MSE。本次任务 3 的分类/回归都用到了 CART 思路
（sklearn 与纯 python CART 代码）。

### 4. 预剪枝与后剪枝
- 预剪枝：在建树时限制 `max_depth`、`min_samples_split`、最小 Gini/MSE 下降量等，提前停止分裂，
  直接降低过拟合风险，训练也更快；
- 后剪枝：先让树长满，再自底向上把“剪掉后验证集不变的子树”替换成叶节点（如代价复杂度剪枝 `ccp_alpha`）。
本次实验用“交叉验证 + 限制最大深度”的方式做预剪枝，并画出了深度与泛化能力的关系曲线。

## 六、数据集说明

- `data/seeds_dataset.txt`：课程提供的 UCI 小麦种子数据集（任务 2），210 个样本、7 个连续特征、3 个类别
  （Kama / Rosa / Canadian，每类 70 个），制表符分隔，最后一列是类别编号 1/2/3。

## 七、主要实验结果
### 任务 1（ID3 / C4.5 原理与验证）
- 天气数据标签熵 `Ent(D) = 0.9403`；各特征信息增益（ID3）与信息增益率（C4.5）：
  outlook 0.2467 / 0.1564、humidity 0.1518 / 0.1518、windy 0.0481 / 0.0488、temperature 0.0292 / 0.0188。
  两者都选 **outlook** 作根节点，但 C4.5 用增益率修正了 ID3 对多取值特征的偏好。
- ID3 在 `weather_nominal.csv` 上建的树深度 2、叶子 5，训练集准确率 100%；
  C4.5 在 `weather_numeric.csv` 上得到同样结构，但对连续特征学出了 `humidity <= 70.0` 的分裂点（ID3 做不到）。
- sklearn 的决策树（`criterion=entropy`）是二叉树，同数据上深度 4、叶子 7，训练准确率也是 100%。

### 任务 2（种子数据集，训练:测试 = 7:3，分层抽样）
| 方法 | 训练准确率 | 测试准确率 | 测试宏 F1 |
| --- | --- | --- | --- |
| ID3（先离散化，3 箱） | 89.80% | 80.95% | 0.801 |
| C4.5（连续） | 97.28% | 93.65% | 0.937 |
| CART（代码 2） | 99.32% | 90.48% | 0.903 |
| CART（代码 1） | 100.00% | 87.30% | 0.872 |
| sklearn（熵） | 100.00% | 92.06% | 0.920 |

- C4.5 的树深度 6、叶子 11；CART（代码 2）深度 7、叶子 11；sklearn 深度 5、叶子 11。
- sklearn 的 5 折交叉验证准确率：0.881 / 0.857 / 0.905 / 0.929 / 0.762，平均 **86.67%**；交叉验证选出
  最优最大深度为 5。
- 结论：ID3 需要先把连续特征离散化，离散化会损失信息，因此通常不如能直接处理连续值的 C4.5 / CART；
  现有代码在训练集上容易长成“完全树”（训练准确率接近 100%），测试准确率更能反映泛化能力。

### 任务 3（自选数据集：分类 + 回归）
- **分类（wine，178×13，3 类）**：交叉验证选出 `max_depth = 3`（交叉验证准确率 87.00%）；
  sklearn 决策树训练准确率 99.19%、测试准确率 96.30%、测试宏 F1 0.964；
  纯 python CART 训练准确率 100%、测试准确率 98.15%、宏 F1 0.983（训练耗时约 0.22 秒），二者互相印证。
  特征重要性最高的是 color_intensity、flavanoids、proline 等。
- **回归（diabetes，442×10）**：交叉验证选出 `max_depth = 3`（交叉验证 R² = 0.291）；
  sklearn 回归树 MSE = 3616.8、RMSE = 60.1、MAE = 47.0、R² = 0.330；
  纯 python CART 回归树 MSE = 4537.4、RMSE = 67.4、MAE = 52.4、R² = 0.159。
  回归树对连续目标只能做“分段常数”拟合，所以 R² 不会太高，残差图里也能看到明显的分段/带状结构。

## 八、代码与报告撰写建议
1. 任务 1 先讲清 ID3（信息增益）和 C4.5（信息增益率 + 连续值二分）的公式与区别，再用天气数据集手算验证，
   最后调用现有代码建树、和 sklearn 对比，并说明“多叉树 vs 二叉树”“离散 vs 连续”的差异。
2. 任务 2 的关键是：ID3 只能处理离散特征，面对种子数据集这种连续特征必须先离散化（本实验用训练集分位数分 3 箱），
   而 C4.5 / CART 可以直接枚举中点做二分，所以效果更好——这正好体现三种算法的差别。
3. 强调现有代码的兼容性问题：`np.mat` / `np.int` / `np.object` 在 NumPy 2.x 被移除会使 demo 直接报错；
    `id3.classify` 遇到“训练时没见过的取值”会返回 None，需要兜底处理。
4. 讲清预剪枝/后剪枝的区别，并用“交叉验证 + 最大深度”曲线说明深度过大会过拟合、过小会欠拟合。
5. 决策树可视化部分：示例依赖缺失的 `utils.plot_tree`，可自行实现字典树绘制，或用 sklearn 的
   `plot_tree`（matplotlib）与 `export_graphviz`（DOT，可配合 Graphviz 渲染）。
6. 体会：决策树的优点是**可解释性强**（规则一目了然、能给出特征重要性）、对特征缩放不敏感、能同时做分类和回归；
   缺点是**容易过拟合**（需要剪枝或集成）、对连续特征只做“阶梯状”划分，且单棵树方差较大（可用随机森林 / GBDT 改进）。
