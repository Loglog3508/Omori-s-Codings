## 三、核心原理
### 1. 算法流程（Lloyd 算法）
```
1. 初始化：选定 K 个聚类中心；
2. 分配：把每个样本分配到距离最近的中心，得到簇标签；
3. 更新：把每个中心移动到其簇内所有样本的均值位置；
4. 重复 2~3 步，直到中心不再变化（或变化很小）。
```

### 2. 目标函数（簇内误差平方和 SSE / 惯性 inertia）
```
J = Σ_j Σ_{x∈C_j} || x - μ_j ||²
```
K-Means 通过反复“分配—更新”单调地降低 SSE，直到收敛到某个局部最优。

### 3. 老师提供的两份纯 Python 代码
- **KMeans/纯python代码1（`kmeans.py`）**：面向对象写法，`class KMeans(k_clusters, tol, max_iter, n_init)`。
  - `_init_centers_kpp()`：k-means++ 初始化，让初始中心彼此远离；
  - `_kmeans()`：核心算法，分配标签 → 计算重心 → 用中心位移判断收敛；
    发现空簇时返回 `None`（整次运行作废）；
  - `predict()`：运行 `n_init` 次，取 SSE 最小的一次，结果放在 `km.centers_`、`km.sse_`。
- **KMeans/纯python代码2（`kmeans_utils.py` + 3 个 demo）**：函数式写法，
  `init_centroids()` 随机选初始质心、`e_step()` 计算样本归属并累加代价 J、`m_step()` 求均值得到新质心；
  `kmeans_demo1.py` 可视化二维数据的迭代过程与 J 曲线，`kmeans_demo2.py` 用 K-Means 做图像压缩，
  `kmeans_demo3.py` 画 K 与 J 的关系曲线（肘部法）。

### 4. 对代码 1 的 5 点改进（`纯python代码1_KMeans改进版.py`，用“继承 + 重写”的方式）
| 改进 | 内容 | 解决的问题 |
| --- | --- | --- |
| 改进1 | `np.int` / `np.object` 换成内置的 `int` / `object`，并新增 `random_state` 固定随机种子 | 老师代码在当前 NumPy 2.x 上会直接 `AttributeError` 跑不起来；固定种子后结果可复现、可对比 |
| 改进1 续 | 更稳的 k-means++：每个新中心先抽 `n_local_trials = 2 + ln(k)` 个候选，取“加入后平方距离和最小”的那个（贪心） | 初始中心更分散，最终 SSE 更小更稳定 |
| 改进2 | 空簇不再返回 `None`，而是把中心重置到最“孤单”的样本上，并在最后检查一遍保证 k 个非空簇 | 老师代码遇到空簇要靠 `while res is None` 整体重跑，退化数据上会一直跑不出结果 |
| 改进3 | 记录每轮的目标函数 J；用中心位移阈值提前停止 | 老师代码不记录过程，画不出收敛曲线 |
| 改进4 | 距离矩阵改为矩阵运算 `‖x-c‖² = ‖x‖² - 2x·c + ‖c‖²` 一次算完 | 老师代码用 for 循环逐簇计算，样本多时较慢 |
| 改进5 | 用最终中心重新分配后再算 SSE；并内置纯 numpy 的轮廓系数 | 老师代码的 `sse_` 用的是“更新中心之前”那一次分配留下的距离矩阵，数值偏大 |

### 5. 如何选择簇数 K
- **肘部法（elbow）**：画出不同 K 对应的 SSE 曲线，取下降速度明显变缓的“拐点”。
- **轮廓系数（silhouette）**：取值 [-1, 1]，越大说明簇内越紧凑、簇间越分离。
  对每个样本 i：`a(i)` 为到同簇其他样本的平均距离，`b(i)` 为到最近其他簇的平均距离，
  `s(i) = (b(i) - a(i)) / max(a(i), b(i))`，轮廓系数为所有 `s(i)` 的平均值。

### 6. 聚类效果评估
聚类是无监督任务，没有标签时看 SSE 和轮廓系数；有真实标签时可额外对比：
- **聚类准确率**：用匈牙利算法把簇编号与真实类别做最大匹配后计算准确率。
- **ARI（调整兰德指数）** 与 **NMI（标准化互信息）**：衡量聚类划分与真实划分的一致程度，越大越好。

## 七、主要实验结果
- **任务 1（理解并改进代码 1）**
  - 老师代码在三个高斯簇上的自测结果：SSE = 569.14，轮廓系数 = 0.5473，聚类准确率 = 0.9567。
  - 老师代码的两个问题：①`np.int` / `np.object` 在 NumPy 2.x 已被移除，原样运行会直接报错；
    ②在退化数据（5 个重合样本 + 1 个远点、K=3）上会因空簇返回 `None`，`predict()` 里的
    `while res is None` 会一直重跑；改进版同样数据上能正常返回结果，并保证 k 个非空簇。
  - 收敛性：目标函数 J 每轮都在下降（1068.05 → 570.52 → 569.26 → 569.14），4 轮即收敛。
  - 改进 4：同为 5000 个样本、64 维、10 簇，算 50 次距离矩阵，老师代码 0.490 秒 → 改进版 0.069 秒，**快约 7.1 倍**。
  - 改进 5：限定 3 轮迭代时，老师代码报告的 SSE = 578.25，用它的最终中心重新计算只要 574.71（偏大 3.54）。
  - 改进 1、2 的效果（8 簇、15 维、每簇 250 个样本的合成数据，各跑 20 次）：
    随机初始化 SSE 均值 128949.6（标准差 50885.7）→ 改用 k-means++ 后降到 29575.1（标准差 0），**平均下降约 77.1%**；
    让随机初始化配合多次重启（n_init = 10）则降到 74917.8（标准差仅 34.2），**再下降约 41.9%**。
- **任务 2（种子数据集，K=3）**
  - 代码 1：SSE = 430.66，轮廓系数 = 0.4007，聚类准确率 = 0.9190，ARI = 0.7733，NMI = 0.7279。
  - 代码 2：SSE = 431.17，轮廓系数 = 0.4039，聚类准确率 = 0.9381，ARI = 0.8227，NMI = 0.7753，5 轮收敛。
  - 两份代码互相印证，都能把三个小麦品种较好地分开；代码 2 的结果甚至略好一些，说明多次随机初始化有助于跳出较差的局部最优。
- **任务 3（手写数字，K=10）**
  - sklearn：SSE = 69813.6，轮廓系数 = 0.1410，ARI = 0.5344，NMI = 0.6712，聚类准确率 = 0.6628；
  - 老师代码 1：SSE = 69463.9，轮廓系数 = 0.1405，ARI = 0.4427，聚类准确率 = 0.5743；
  - 改进版：SSE = 69478.0，轮廓系数 = 0.1407，ARI = 0.4812，聚类准确率 = 0.6149。
  - 三者的 SSE 几乎一致，说明纯 Python 实现是正确的；改进版比老师代码 1 更快（0.24 秒 vs 0.56 秒），
    聚类指标也更好。注意：K-Means 只优化 SSE，SSE 最小的解不一定与真实标签最一致，
    所以 ARI 等指标与 sklearn 略有出入属于正常现象。
