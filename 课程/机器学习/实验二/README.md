## 三、核心原理
### 1. 算法流程（Lloyd 算法）
```
1. 初始化：选定 K 个聚类中心；
2. 分配：把每个样本分配到距离最近的中心，得到簇标签；
3. 更新：把每个中心移动到其簇内所有样本的均值位置；
4. 重复 2~3 步，直到中心不再变化（或变化很小）。
```

### 2. 目标函数（簇内误差平方和 SSE / 惯性 inertia）
```
J = Σ_j Σ_{x∈C_j} || x - μ_j ||²
```
K-Means 通过反复“分配—更新”单调地降低 SSE，直到收敛到某个局部最优。

### 3. 对基础版本的 5 点改进（纯python代码1）
- **改进 1：k-means++ 初始化**——按“到已有中心距离的平方”做加权抽样选中心，并对每个新中心抽取多个候选、取使平方距离和下降最多的那个（贪心 k-means++），让初始中心彼此远离，明显降低陷入较差局部最优的概率。
- **改进 2：多次重启（n_init）**——用不同随机种子跑多遍，取 SSE 最小的一次，使结果对初始化不再敏感。
- **改进 3：收敛判据**——中心最大位移小于 `tolerance` 时提前停止，不必跑满迭代次数，同时记录每轮 SSE 便于画收敛曲线。
- **改进 4：空簇处理**——若某个簇分不到样本，就把该中心重置到“离最近中心最远”的样本上，避免出现无意义中心。
- **改进 5：向量化距离计算 + 轮廓系数**——用矩阵运算一次性算完所有样本到所有中心的距离（`||x-c||² = ||x||² - 2x·c + ||c||²`），并内置纯 numpy 的轮廓系数，便于选择簇数 K。

### 4. 如何选择簇数 K
- **肘部法（elbow）**：画出不同 K 对应的 SSE 曲线，取下降速度明显变缓的“拐点”。
- **轮廓系数（silhouette）**：取值 [-1, 1]，越大说明簇内越紧凑、簇间越分离。
  对每个样本 i：`a(i)` 为到同簇其他样本的平均距离，`b(i)` 为到最近其他簇的平均距离，
  `s(i) = (b(i) - a(i)) / max(a(i), b(i))`，轮廓系数为所有 `s(i)` 的平均值。

### 5. 聚类效果评估
聚类是无监督任务，没有标签时看 SSE 和轮廓系数；有真实标签时可额外对比：
- **聚类准确率**：用匈牙利算法把簇编号与真实类别做最大匹配后计算准确率。
- **ARI（调整兰德指数）** 与 **NMI（标准化互信息）**：衡量聚类划分与真实划分的一致程度，越大越好。

## 七、主要实验结果
- **任务 1（自测与改进）**：三个高斯簇上 SSE = 569.14，4 轮即收敛，轮廓系数 = 0.5473，聚类准确率 = 0.9567。
  在更难的合成数据（8 簇、15 维）上：随机初始化的 SSE 均值为 128949.6（标准差 50885.7）；
  改用 k-means++ 后降到 29575.1（标准差 0），**平均 SSE 下降约 77.1%**；
  让随机初始化配合多次重启（n_init = 10）则降到 74917.8（标准差仅 34.2），**再下降约 41.9%**。
- **任务 2（种子数据集，K=3）**：SSE = 430.66，轮廓系数 = 0.4007，聚类准确率 = 0.9190，ARI = 0.7733，NMI = 0.7279。
- **任务 3（手写数字，K=10）**：sklearn 的 KMeans 轮廓系数 = 0.1394，ARI = 0.5344，NMI = 0.6712，聚类准确率 = 0.6628；
  自实现 K-Means 的 SSE（69478.0）与 sklearn（69813.6）几乎一致，说明纯 Python 实现是正确的。
