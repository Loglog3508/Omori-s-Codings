# 机器学习 实验六：综合练习

实验题目：**综合练习**

## 一、题目
从目前所学算法中选取一种或多种算法解决实际中的问题，并写清处理流程和核心算法。

本练习选取「**乳腺癌良恶性诊断**」这个实际二分类问题，串联本学期学过的算法：
- 实验二：K-Means 聚类（无监督探索）
- 实验五：数据预处理（StandardScaler）+ 交叉验证（StratifiedKFold / cross_val_score）
- 实验一：逻辑回归
- 实验三：决策树（含可视化）
- 实验四：神经网络（MLPClassifier）
- 对照模型：SVM

## 二、处理流程
1. 数据探索：样本数、特征数、类别分布
2. 无监督探索：K-Means 聚类 + PCA 降维可视化，用 ARI 衡量聚类与真实标签的一致性
3. 多模型 5 折交叉验证对比（逻辑回归 / 决策树 / SVM / 神经网络）
4. 选最优模型做最终评估（准确率 / 精确率 / 召回率 / F1 / 混淆矩阵 / ROC 曲线）
5. 决策树可视化

## 四、运行方法
依赖库：`numpy`、`matplotlib`、`scikit-learn`。

```powershell
python task_综合练习_乳腺癌诊断.py
```

脚本使用 sklearn 内置的 `load_breast_cancer`（569 个样本、30 个特征、2 类），无需联网下载数据，运行后自动把结果图保存到 `结果图/`。

## 五、主要结果（供参考）
- K-Means(2 类) 与真实标签的 ARI 约 0.65，说明无监督聚类已能大致区分两类。
- 5 折交叉验证准确率：SVM(RBF) ≈ 0.9772，逻辑回归 ≈ 0.9737，神经网络 MLP ≈ 0.9737，决策树 ≈ 0.9227。
- 逻辑回归测试集：准确率 0.9825，F1 0.9861，AUC 接近 1。
