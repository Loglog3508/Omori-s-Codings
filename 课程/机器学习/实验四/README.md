# 机器学习 实验四：深度学习初步

## 一、实验题目与目的

实验题目：**深度学习初步**

实验目的和要求：
- 理解感知机的原理与特点，了解神经网络的使用方法和应用场景。
- 使用原生 Python 与 NumPy 实现二层神经网络。
- 理解误差反向传播算法，并在二层网络基础上实现三层神经网络。
- 使用神经网络解决一个实际分类问题。

## 三、核心原理

### 1. 感知机

感知机先计算输入的加权和，再通过阶跃函数输出类别：

```text
y = 1,  当 w·x + b > 0
y = 0,  当 w·x + b ≤ 0
```

单层感知机只能解决线性可分问题。XOR 不是线性可分问题，但可以把 NAND、OR 和 AND 感知机组合成两层结构解决，因此多层结构具有更强的表达能力。

### 2. 二层神经网络

本实验沿用指导书的层式设计：

```text
输入 → Affine1 → ReLU → Affine2 → SoftmaxWithLoss
```

其中 Affine 层完成线性变换，ReLU 引入非线性，Softmax 将输出转成类别概率，交叉熵衡量预测与真实标签之间的差异。

### 3. 三层神经网络

在二层网络中再增加一个隐藏层：

```text
输入 → Affine1 → ReLU → Affine2 → ReLU → Affine3 → SoftmaxWithLoss
```

对应参数由 `W1、b1、W2、b2` 增加为 `W1、b1、W2、b2、W3、b3`。前向传播按顺序执行各层，反向传播则从损失层开始按相反顺序计算梯度。

### 4. 误差反向传播

反向传播利用链式法则，将损失函数对输出的梯度逐层向前传递。以 Affine 层 `Y=XW+b` 为例：

```text
∂L/∂X = (∂L/∂Y) Wᵀ
∂L/∂W = Xᵀ (∂L/∂Y)
∂L/∂b = Σ(∂L/∂Y)
```

实验同时使用中心差分数值梯度检查反向传播。二层和三层网络各参数的最大归一化误差约为 `10^-12`，说明梯度实现正确。

## 六、主要实验结果

### 任务 1：二层神经网络

- 感知机正确实现 AND、NAND、OR；组合两层感知机后正确实现 XOR。
- 数值梯度与反向传播梯度的最大归一化误差小于 `10^-12`。
- 双月数据训练准确率为 **96.67%**，测试准确率为 **97.00%**。
- 非线性分类边界表明隐藏层和 ReLU 能解决单条直线无法分开的数据。

### 任务 2：三层神经网络

- 新增 `Affine2 → ReLU2` 隐藏层与第三组权重、偏置。
- 三层网络各参数的梯度检查误差约为 `10^-12`。
- 在同心圆数据上，二层网络和三层网络的测试准确率均达到 **100%**；三层网络最终损失为 **0.0059**，低于二层网络的 **0.0077**。
- 该简单数据上二层网络已经具备足够表达能力，因此增加层数未继续提高准确率，但验证了扩展方法和反向传播实现。

### 任务 3：手写数字分类

- 数据集共 1797 个 8×8 灰度数字图像，按 8:2 分层划分为 1437 个训练样本和 360 个测试样本。
- 网络结构为 `64 → 64 → 32 → 10`，使用 ReLU、Softmax 交叉熵和小批量梯度下降训练 50 轮。
- 测试准确率为 **96.94%**，宏平均 F1 为 **96.92%**。
- 数字 3 和 5 的 F1 达到 1.00；数字 1 与 8 较容易混淆，是后续可重点改进的类别。
