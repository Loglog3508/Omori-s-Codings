# 数据集说明

实验四不需要额外下载数据文件，三个任务的数据均在脚本运行时加载：

| 任务 | 数据来源 | 规模 | 用途 |
| --- | --- | --- | --- |
| 任务 1 | `sklearn.datasets.make_moons` | 400 个样本、2 个特征、2 类 | 验证二层神经网络的非线性分类能力 |
| 任务 2 | `sklearn.datasets.make_circles` | 600 个样本、2 个特征、2 类 | 对比二层和三层神经网络 |
| 任务 3 | `sklearn.datasets.load_digits` | 1797 个样本、64 个特征、10 类 | 手写数字分类 |

`digits` 中每个样本原本是一张 8×8 灰度图像。训练时将图像展开成 64 维向量，并使用 `StandardScaler` 按训练集均值和标准差进行标准化。
