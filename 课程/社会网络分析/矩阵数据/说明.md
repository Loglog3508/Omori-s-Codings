## 四、UCINET 操作步骤

1. **（重要）路径**：把 `矩阵数据` 文件夹复制到不含中文、空格的路径，如 `C:\sna\`。UCINET 6 对中文路径/中文文件名支持差，容易保存 `. ##h` 失败。
2. **导入 2-mode（推荐：直接粘贴，已实测可行）**：Excel 打开 `author_keyword_2mode_kwge2.xlsx` → 选中含标签的整块区域（A1 到右下角）→ `Ctrl+C`；UCINET 工具栏 `Matrix` 按钮（或 `Data → Spreadsheets`）打开 Spreadsheet 编辑器 → 设 `Rows 491 / Cols 76` → 点左上角 A1 → `Ctrl+V`。标签会一起落位（A1 显示 `作者＼关键词`，左侧 491 个作者、顶行 76 个关键词）。
3. **保存成 UCINET 数据集**：Spreadsheet 编辑器 `File → Save`（或 `Ctrl+S`）→ 命名 `KW2M`，在当前文件夹生成 `KW2M.##h / KW2M.##d`。
   - ⚠️ **不要**走 `Data → Import via spreadsheet → Full matrix w/ multiple sheets` 去读 `.xls`：UCINET 6.199 借 Excel COM 自动化读表，本机实测会报 `Could not convert variant of type (Dispatch) into type (Double)`（Excel 是否打开、文件是 .xls 都无关，属于版本兼容问题）。
4. **转 1-mode**：`Data → Affiliations (2-mode to 1-mode)` → Input dataset 选 `KW2M` → `Column` → OK，写为新数据集（如 `KW1M`）。
5. **中心度**：`Network → Centrality → Degree` → 选 `KW1M` → OK，得到每个关键词的度中心度（结果可对照本目录 xlsx 的 `词频与度中心度` 表）。
6. **画图**：`Visualize → NetDraw` → `File → Open → Ucinet dataset` → 选 `KW1M. ##h`；`Layout → Graph-Theoretic layout → Spring embedding` 或 `Circle`；`Analysis → Centrality measures` 可选节点大小；`Properties → Nodes` 设标签显示与字号（中文标签需在 `File → Properties → Labels` 里确认）。

## 五、数据特点与注意事项

1. **中心节点过强**：`数字化转型` 是检索词本身，152/206 篇文献都带它，网络呈「一个超级中心 + 若干子群」。作图时保留它能体现核心热词地位；若想看子结构，可在 NetDraw 里删掉该节点，或看 1-mode 表中去掉该行/列后的子矩阵。
2. **同义变体未合并**：`企业数字化转型`(12)、`教育数字化转型`(4)、`城市数字化转型`(3)、`财务数字化转型`(3)、`银行数字化转型`(2) 等与 `数字化转型` 分开统计。若合并，中心度会进一步向该词集中。
3. **同名作者未消歧**：不同单位的同名作者被当成同一人；对关键词网络的影响很小。
4. **共现权重计的是作者数**：2-mode 是「作者×关键词」，多人合作论文会让其关键词共现权重被作者数放大。这是指导书流程（Affiliations Column）的固有口径；若需按「文献数」计权，需另做「文献×关键词」矩阵。
5. **检索词提示**：全量数据 208 篇均为 2024–2026 年网络首发，时效性强；但 `数字化转型` 一词的中心度过高，写报告时应说明「该词为检索主题词，其高中心度部分来自检索策略」。若想展示更均衡的热点结构，可考虑在检索时用 `数字化转型 - 数字化转型` 之类排除自身词（知网支持 `NOT`），但这会改变样本，需与老师确认。
